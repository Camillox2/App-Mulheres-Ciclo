# 🤖 Como Configurar o Chatbot com Gemini AI

## ✨ **GRATUITO e SEM BACKEND!**

O chatbot usa a API **Google Gemini AI** que é **100% gratuita** e **sem limite de tempo**!

---

## 🚀 **Passo a Passo:**

### **1. Obter API Key (Gratuita)**
1. Acesse: https://makersuite.google.com/app/apikey
2. Faça login com sua conta Google
3. Clique em **"Create API Key"**
4. Copie a chave gerada (ex: `AIzaSyD...`)

### **2. Configurar no App**
1. Abra o arquivo: `config/api.ts`
2. Substitua `'SUA_API_KEY_AQUI'` pela sua chave:
```typescript
GEMINI_API_KEY: 'AIzaSyD_sua_chave_aqui_1234567890',
```
3. Salve o arquivo

### **3. Pronto! 🎉**
- O chatbot já funciona
- Limite gratuito: **1500 requests/dia**
- Sem expiração
- Sem necessidade de cartão
